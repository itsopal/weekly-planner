# 📅 Weekly Planner — نسخه وب

پلنر هفتگی تحت وب با Flask (بک‌اند پایتون + فرانت HTML/CSS/JS ساده، بدون فریم‌ورک).

## اجرا

```bash
cd web_planner
pip install --require-hashes -r requirements.lock
python app.py
```

بعد مرورگر رو باز کن: **http://127.0.0.1:5000**

## امکانات

- هفته‌بندی با تاریخ واقعی + Previous / Next / Today
- هر خونه = تیک انجام + یادداشت (ذخیره خودکار هنگام تایپ)
- مدیریت ستون‌ها (افزودن / تغییرنام / حذف) از داخل برنامه
- پیشرفت روزانه و هفتگی + درصد
- استریک 🔥 برای هر ستون
- هایلایت ردیف امروز
- کپی هفته قبل، آمار، خروجی CSV
- حالت تیره / روشن 🌙
- نگه‌داری تغییرات آفلاین در مرورگر و تلاش خودکار برای همگام‌سازی پس از اتصال
- تاریخچهٔ ۱۰ نسخهٔ اخیر و بازیابی از داخل برنامه

## انتقال دیتا از نسخه دسکتاپ

فرمت فایل دیتا یکی است — کافیه فایل `planner_data.json` نسخه
دسکتاپ (Tkinter) رو کپی کنی کنار `app.py` و سرور رو اجرا کنی.

## پشتیبان و حالت آفلاین

۱۰ نسخهٔ اخیر در پوشهٔ `planner_backups/` نگه‌داری می‌شود و از دکمهٔ Backup History قابل بازیابی است. تغییرات خانه‌ها در زمان قطع اینترنت در حافظهٔ محلی مرورگر ذخیره و پس از اتصال دوباره ارسال می‌شوند. برای کارکرد آفلاین، برنامه را یک‌بار با اتصال اینترنت و روی HTTPS یا localhost باز کن. دادهٔ ذخیره‌شده در مرورگر رمزگذاری نشده است.

## ساختار پروژه

```
web_planner/
├── app.py              # سرور Flask + API + ذخیره‌سازی
├── requirements.txt         # وابستگی مستقیم برنامه، با نسخهٔ ثابت
├── requirements.lock        # نسخه‌های دقیق وابستگی‌ها برای نصب تکرارپذیر
├── requirements-dev.txt     # ابزارهای توسعه و تست
├── requirements-dev.lock   # قفل وابستگی‌های توسعه و تست
├── planner_data.json       # پس از اولین ذخیره ساخته می‌شود؛ محلی و نادیده‌گرفته‌شده در Git (+ .bak)
├── planner_backups/        # حداکثر ۱۰ نسخهٔ زمان‌دار؛ محلی و نادیده‌گرفته‌شده در Git
├── templates/
│   └── index.html      # صفحه اصلی
└── static/
    ├── style.css       # استایل + تم تیره/روشن
    └── app.js          # منطق فرانت (بدون فریم‌ورک)
```
